# انباربان (AnbarBan)

اپلیکیشن انبارداری فارسی با رویکرد آفلاین‌محور برای اندروید و ویندوز.

## اصول پروژه
- فارسی و راست‌چین
- ذخیره‌سازی محلی و حفظ سوابق
- ثبت مستند ورود، خروج و اصلاح موجودی
- پشتیبان‌گیری و بازیابی
- اشتراک ماهانه با مجوز دیجیتال امضاشده

## وضعیت
نسخه اولیه ساختار پروژه و داشبورد نمایشی را دارد.
اتصال پایگاه داده و عملیات واقعی انبار هنوز پیاده‌سازی نشده‌اند.
